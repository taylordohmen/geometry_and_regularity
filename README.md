This repo contains implementations of finite automata and streaming string transducers that operate over strings comprised of pairs of numeric digits (typically binary).
These are viewed as machines modeling relations/functions over digital expansions of numbers.
In turn, these functions/relations are interpreted geometrically in the unit square of the euclidian plane.
The other file in the repo specify particular instances of these models and plot their corresponding functions/relations in the plane, allowing to explore the geometric shapes and patterns that these models are able to represent.
